# stil.typ

Gemeinsamer Stil aller eingebauten Vorlagen. Jede Vorlage legt `stil.typ` als
`templates/stil.typ` ins neue Projekt (siehe `STIL` in `src/templates.rs`).

Dieselbe Datei gibt es als lokales Typst-Paket `@local/stil:0.1.0`
(`~/Library/Application Support/typst/packages/local/stil/0.1.0/lib.typ`).
Nach Änderungen hier die Datei dorthin kopieren. Die Regeln stehen in `STIL.md`.
