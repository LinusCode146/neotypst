Deine Texte sind jetzt geschützt: NeoTypst führt einen Verlauf, erkennt Änderungen von außen und hält den Stil in alten Projekten aktuell.

## Neu

- **Verlauf:** ⌘K → „Verlauf dieser Datei“ zeigt frühere Stände mit Uhrzeit und einem Vergleich zum jetzigen Text. Gesichert wird beim Speichern höchstens alle 2 Minuten, sofort aber, wenn viel Text auf einmal verschwindet. „Wiederherstellen“ lässt sich mit ⌘Z rückgängig machen. Der Verlauf liegt im Projekt unter `.neotypst/verlauf/`.
- **Änderungen von außen:** Ändert ein anderes Programm die offene Datei, lädt NeoTypst sie beim Zurückwechseln neu. Hast du selbst noch ungespeicherte Änderungen, fragt eine Karte über dem Editor, welche Fassung gelten soll. Bisher hat das automatische Speichern fremde Änderungen überschrieben.
- **Sicheres Speichern:** Dateien werden erst vollständig geschrieben und dann ersetzt. Auch bei einem Absturz bleibt keine halbe Datei zurück.
- **Stil aktualisieren:** Ist `templates/stil.typ` oder eine Vorlagen-Datei in einem Projekt älter als in NeoTypst, erscheint beim Öffnen ein Hinweis mit den Unterschieden. In der Projektübersicht aktualisiert „Stil in N Projekten veraltet“ alle alten Kopien auf einmal. Von Hand angepasste Dateien bleiben unangetastet, alte Fassungen kommen in den Verlauf.
- **`@local/stil`** stellt NeoTypst jetzt selbst bereit, immer in der aktuellen Fassung.

## Unter der Haube

- Automatische Tests auf macOS und Windows bei jeder Änderung. Releases entstehen nur noch aus geprüftem Code.
- Tastenkürzel, Befehlspalette und Tooltips kommen aus einer gemeinsamen Liste. Der Editor rendert beim Tippen weniger neu.

## Installation unter macOS

Wer 0.2.0 oder neuer hat, bekommt das Update über die Karte in der App.

Neu installieren: `NeoTypst_0.5.0_Apple-Silicon.dmg` oder `NeoTypst_0.5.0_Intel.dmg` herunterladen, öffnen und `NeoTypst.app` auf „Programme“ ziehen. Welche Version du brauchst, steht unter  → Über diesen Mac.

**Erster Start:** Die App ist nicht mit einem Apple-Entwicklerzertifikat signiert. Falls macOS sie blockiert: **Systemeinstellungen → Datenschutz & Sicherheit → „Dennoch öffnen“**, oder im Terminal `xattr -dr com.apple.quarantine /Applications/NeoTypst.app`.

## Installation unter Windows

Wer 0.4.1 hat, bekommt das Update über die Karte in der App.

1. `NeoTypst_0.5.0_Windows-Setup.exe` unten bei den Assets herunterladen.
2. Die Datei doppelklicken. Der Installer braucht keine Administratorrechte.
3. **Warnung „Der Computer wurde durch Windows geschützt“:** Die App ist nicht mit einem Microsoft-Zertifikat signiert. Auf **„Weitere Informationen“** klicken, dann auf **„Trotzdem ausführen“**.
4. Dem Installer folgen. Danach steht NeoTypst im Startmenü.

Unter Windows fehlen weiterhin die Rechtschreibprüfung und „Rückgängig“ nach dem Löschen einer Datei.
